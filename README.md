## 👋 About me

I build AI systems that make it from notebook to production — multi-agent workflows, RAG pipelines and forecasting models, together with the MLOps plumbing that keeps them running.

- 🧠 **AI Engineer** at [Plant Supervision ApS](https://github.com/Plant-Supervision) (Aalborg, Denmark) — owning features across data, LLM and agentic-AI workflows, from prototype to deployed service. Shipped an end-to-end MVP that improved on the existing manual workflow by **75%**.
- 🎓 **MSc Business Data Science**, Aalborg University (2024 – 2026). Thesis: *Identifying and Mitigating Gender Bias in Resume Screening with Agentic AI* — fairness metrics across embeddings, RAG retrieval, LLM screening and prompt design.
- 🧰 Daily drivers: **Python · TypeScript · C#** — CrewAI / LangGraph / LangChain, FastAPI, React, PyTorch, Azure.
- 📜 Microsoft Certified **Azure Data Scientist Associate (DP-100)**.
- 💼 Open to AI / ML engineering opportunities.
- 🎸 Off-keyboard: classical guitar, historical places and mountains, and cooking Thai, Italian and Indian food.
